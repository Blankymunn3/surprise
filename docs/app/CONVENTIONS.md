# 코딩 규칙

## 공통

- **주석과 커밋 메시지는 한국어.** 이 저장소를 읽는 사람이 한국어를 씁니다.
- 주석은 **왜** 를 적습니다. 무엇을 하는지는 코드가 말합니다.
  ```kotlin
  // 나쁨: 사진을 업로드한다
  // 좋음: 신호가 약한 곳에서 하염없이 기다리지 않도록 25초에서 끊습니다.
  //       끊기면 기기 저장으로 넘어가 사진을 잃지 않습니다.
  ```
- 웹과 동작이 달라지면 안 되는 규칙(지역 코드, 업로드 실패 처리)은
  코드 옆에 **웹의 어느 파일과 같은 규칙인지** 적어 둡니다.
- 파일 하나가 300줄을 넘으면 나눌 때가 된 것입니다.

## 이름

| 대상 | 규칙 | 예 |
|---|---|---|
| UseCase | `동사 + 명사 + UseCase` | `UploadRegionPhotoUseCase` |
| Repository | `명사 + Repository` | `RegionPhotoRepository` |
| MVI | `화면 + State/Intent/Effect` | `MapState`, `MapIntent` |
| Composable | 명사 | `RegionPanel`, `SearchField` |
| 테스트 | 한국어 문장으로 | ``fun `사진이 없으면 지우기 버튼을 숨긴다`()`` |

**도메인 용어는 웹과 같은 말을 씁니다.** 지역=Region, 시도=Subdivision,
도장깨기=Stamp. 새 말을 만들지 않습니다.

## 코틀린

- Kotlin 2.x, JDK 21, Compose Material 3
- `!!` 금지. 널이 아님이 확실하면 타입에서 없애고, 아니면 분기합니다
- 도메인에서 예외를 던지지 않고 `Result` 로 돌려줍니다
- 문자열을 코드에 직접 쓰지 않습니다 → `strings.xml`
- `internal` 을 기본으로. `public` 은 다른 모듈이 정말 쓸 때만
- 데이터 클래스는 도메인·DTO 를 분리합니다. `RegionDto` → `Region` 매핑은 data 계층에서

## 스위프트

- Swift 6, Strict Concurrency, SwiftUI, Observation
- 상태 변경은 `@MainActor`, 무거운 일은 `Task.detached` 밖으로
- 강제 언래핑(`!`) 금지. `guard let` 으로 빠져나갑니다
- 프로토콜은 `Repository` 접미사로 도메인에 두고 구현은 data 패키지에

## 지역 코드 — 절대 바꾸지 않기

사진은 지역 코드로 저장됩니다. 코드가 바뀌면 **이미 올린 사진이 지도에서 사라집니다.**

| 코드 | 뜻 |
|---|---|
| `11140` | 국내 시군구 |
| `C-JPN` | 나라 |
| `P-JPN-12` | 해외 시도 |
| `bali` | 좌표만 있는 추억 장소 |

파일 이름은 `spaces/<공간ID>/regions/<코드>.jpg`. 코드에 `[A-Za-z0-9_-]` 외 문자가
들어오면 `_` 로 바꿉니다 (경로를 벗어나지 못하게). 공간 ID 도 같은 규칙으로 검사합니다.

## 사진 규칙 (웹과 동일)

- 올리기 전에 **가로·세로 최대 760px, JPEG 품질 0.72** 로 줄입니다
- 목록 조회 15초 / 업로드 25초 제한
- 업로드 성공하면 기기 사본 삭제, 실패하면 기기에 저장하고 알림
- **사진은 캐시하지 않습니다**

## 커밋

- 제목은 한국어 한 줄, 무엇이 달라지는지
- 본문에 **왜** 와 **어떻게 확인했는지**
- 되돌린 결정은 그 이유를 남깁니다

## 테스트

| 대상 | 얼마나 |
|---|---|
| Reducer | 전부. 상태 전이가 앱의 핵심입니다 |
| UseCase | 규칙이 있는 것 전부 |
| Repository | 파싱·실패 처리 |
| UI | 꼭 필요한 흐름만 |

테스트 이름은 **무엇을 보장하는지** 한국어로 적습니다.

## CI 규칙

- PR 마다 두 플랫폼 빌드 + 테스트가 돌아야 합니다
- 안드로이드는 우분투, iOS 는 macOS 러너
- **빨간 CI 를 두고 머지하지 않습니다**
- 포맷은 ktlint / swift-format 으로 맞추고, 사람이 손으로 고치지 않습니다

## 개발 환경 주의

이 저장소의 작업 컨테이너에서는 **`dl.google.com` 이 막혀 있어 안드로이드 빌드가 안 됩니다.**
그래서 컴파일 확인은 CI 에서 합니다. iOS 는 맥이 필요해 마찬가지입니다.
로컬에서 확인할 수 있는 것(문서·순수 코틀린 로직·JSON 데이터)은 로컬에서 확인합니다.
